# Load Balancer Simulator

A minimal React/Vite client-side simulation of request routing.

## Features
- Round Robin, Least Connections and Weighted routing
- Live traffic simulation
- Server health/failure toggle
- Add/restart/disable servers
- Request, success, failure and latency metrics
- Live request log
- Traffic distribution visualization
- No backend required

## Run
```bash
npm install
npm run dev
```

For production:
```bash
npm run build
```
